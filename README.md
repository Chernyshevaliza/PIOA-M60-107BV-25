# Лабораторная работа №3

### Структура проекта
- `src/db/__main__.py` — точка входа
- `src/db/tui.py` — консольный интерфейс
- `src/db/backend/memory.py` — класс BookTable
- `src/db/backend/errors.py` — пользовательские исключения
- `tests/test_memory.py` — тесты

### Функциональность (основное задание)
- Добавление книг (ID, название, автор, год)
- Просмотр всех книг
- Поиск с фильтрацией по любому полю
- Обработка ошибок (дубликат ID, пустые поля, отрицательный год)

### Дополнительные задания 
- Обновление записей
- Удаление записей
- Сортировка записей по выбранному полю (asc/desc)
- Класс для пользовательского интерфейса (BookUI)

python3 -m src.db
